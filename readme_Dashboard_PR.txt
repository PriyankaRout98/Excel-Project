A. This is an Interactive Excel Dashboard project focuses on transforming raw sales data into a visually clear and dynamic dashboard using Excel’s visualization and interactivity features. 

B. It allows users to explore data across regions, years, categories, and more.

C. It has Dynamic Charts that updates automatically with filters.

D. This is a Clean layout with responsive visual elements.

E. Dashboard Features
	1. Total Sales
	2. Average Sales
	3. Transaction Count
	4. Total Quantity Ordered
	5. Region-wise Transaction Distribution
	6. Category-wise Transaction Breakdown
	7. Monthly Quantity Trend Line
	8. Top 5 Cities by Sales
	9. Ship Mode Sales % Pie Chart
	10. Consumer Type Quantity Ordered
	11. Slicers for Region & Year
